# VYRO Custom Studio garment asset

The current Studio garment is `vyro-football-jersey-realistic.glb`, sourced from
the `FrancescoCastaldi/mini-jersey-studio` repository:

- Source: https://github.com/FrancescoCastaldi/mini-jersey-studio
- Asset path: `models/shirt.glb`
- License: MIT, as published in the repository `LICENSE` file
- Source commit used for this integration: repository default branch at the time of the local asset audit on 2026-10-14

The asset is a high-fidelity procedural cycling-jersey mesh from the source
project. It is used as a sports-jersey base in the isolated 8086 Studio only.
The VYRO editor applies its own front/back design layers as an overlay. No
brand logo, club crest, player name, or third-party commercial artwork was
copied into the asset.
